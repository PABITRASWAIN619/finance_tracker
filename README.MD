# 💰 Finance Tracker Pro AI

A modern AI-powered Finance Tracker web application built using HTML, CSS, and JavaScript.  
Track your daily expenses, manage budgets, visualize spending analytics, and get smart financial insights instantly.

---

# 🚀 Features

✅ Beautiful Modern UI  
✅ Dark / Light Mode  
✅ Mobile Responsive Design  
✅ User Login Welcome Screen  
✅ Save Username using LocalStorage  
✅ Budget Management  
✅ Expense Tracking System  
✅ Expense Categories  
✅ Edit Expense Option  
✅ Delete Expense Option  
✅ Search Expenses  
✅ Filter by Category  
✅ AI Financial Insights  
✅ Doughnut Analytics Chart  
✅ LocalStorage Data Persistence  
✅ Date Validation  
✅ Sticky Navbar  
✅ Animated Hover Effects  
✅ Smooth Scrolling Footer Links
